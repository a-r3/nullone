# NullOne Monitoring Sources

This is a starting map, not a closed list.

The agent should discover additional reliable sources over time.

## Tier 1 — Primary sources

Prioritize these for verification:

- OpenAI
- Anthropic
- Google / Google DeepMind
- Meta AI
- Microsoft / Microsoft AI
- NVIDIA
- Apple
- GitHub
- Hugging Face
- xAI
- major AI labs and model developers
- official product blogs
- official release notes
- official developer documentation

## Tier 2 — Technology journalism

Use for discovery and context, then seek primary sources when appropriate:

- TechCrunch
- The Verge
- Ars Technica
- Wired
- Engadget
- VentureBeat
- other credible technology publications discovered over time

## Tier 3 — Discovery/community signals

Use for discovery, NOT automatically as final factual authority:

- Hacker News
- Reddit
- X/public social discussion
- Product Hunt
- GitHub trending/activity
- public technology communities

## Azerbaijan/local ecosystem

Monitor:
- important local technology companies
- startup ecosystem developments
- relevant government/digital-sector announcements
- major local product launches and events

Reference accounts may also signal local stories:
- Tedroid
- Technote
- Trilogy.News

## Editorial rule

Discovery source and verification source are not necessarily the same thing.

A Reddit post, X post or reference-account post may reveal a story.
Whenever practical, verify the actual claim from the original source before publication.
