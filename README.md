# NullOne

Infrastructure, editorial rules, prompts, deterministic production scripts and renderer source for the NullOne AI-native Azerbaijani technology media operation.

## Production principle

monitor → verify → score → draft → render → Zernio draft → Telegram preview → human approval → second publish confirmation → publication → result

No blind autonomous publishing.

## Repository role

This repository is the development source for NullOne configuration and production logic.

GitHub merge does not automatically deploy to production.

Production deployment is a separate controlled step after review and validation.
